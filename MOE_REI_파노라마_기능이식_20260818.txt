MOE 파노라마 기능 이식 (2026-08-18)

1. REI 파노라마 촬영 및 합성 기능 이식
- 현재 Pan을 시작점으로 10도 간격 36개 위치, Tilt 2행, 총 72장 촬영
- OpenCV Panorama/Scans 정합, 행 간 수평 위치 보정, 최적 seam 및 8px feather blending
- 촬영 취소, 시작 위치 복귀, 저장 및 화면 표시

2. PAN/TILT SPEED Slider 연동
- 촬영 시작 순간 Slider 값을 전체 촬영 속도로 고정
- 기본 30에서는 30 deg/s 및 1200ms 안정화
- 5~20: 1000ms, 25~35: 1200ms, 40~50: 1500ms

3. 로그
- 촬영, 이동 목표/실제값, 프레임, 정합 상태, seam, 저장, 취소 및 오류
- Debug Console 및 Serilog 파일 동시 기록

4. 최신 기본 파노라마
- Panoramas/Panorama N.jpg 중 가장 큰 번호를 실행 시 자동 표시
- 새 결과는 기존 최대 번호 + 1로 저장
- 생성 파일이 없으면 기존 내장 기본 이미지 사용

5. 더블 클릭 확대 보기
- 파노라마 더블 클릭 시 별도 확대 창
- Wheel 확대, 우클릭 초기화, 더블 클릭 최대화, ESC 닫기

6. MOE 고유 동작 보존
- 기존 MOE 환경부 RTSP 및 Control Agent/Web Agent 설정 유지
- MOE의 HOME 비활성 정책 유지
- 파노라마는 MOE Control Agent TCP와 EO 영상 연결 상태에서 실행

7. 검증
- OpenCvWpfTracking: Debug | x64 Rebuild 성공
- FireCandidateValidator: Debug | x64 Rebuild 성공

8. 확대 보기 렌더 스레드 오류 방어
- 촬영, 정합, 블렌딩, 저장 중에는 더블 클릭 확대 보기를 차단
- 확대창이 열린 상태에서 촬영을 시작하면 먼저 확대창을 닫음
- 최대 8192px 별도 디코딩 및 확대창 소프트웨어 렌더링 적용
- 확대창 생성/표시 예외 처리로 메인 프로그램 종료 방지

9. 고품질 정합 및 seam 계산
- 특징점 등록 해상도 1.0MP, seam 탐색 해상도 0.6MP 적용
- 원본 입력 해상도 최종 합성, 수평 wave correction 명시
- OpenCV 내부 구면 warping, 노출 보정, graph-cut seam,
  multi-band blending을 고해상도 설정으로 사용
- 품질을 우선하여 처리시간과 메모리 사용량은 기존보다 증가

10. 확대 이미지 드래그 이동
- Wheel 포인터 중심 확대/축소
- 확대 후 좌클릭 드래그 상하좌우 이동 및 이동 범위 제한
- 우클릭 시 배율과 위치 동시 초기화

11. PTZ 각도 기반 실사용 속도 최적화
- 10° 간격 36장 중 20° 간격 핵심 프레임 18장을 정합에 사용
- EO Zoom 0~100 광각 조건에서 인접 프레임 중첩 유지
- 특징점 등록 0.8MP, seam 탐색 0.3MP 균형 설정
- 핵심 프레임 실패 시 전체 36장 Panorama 모드 자동 재시도
- 구면 warping, 노출 보정, graph-cut seam, multi-band blending 유지

12. 정합 1분 목표 및 수직 절단 제거
- 정상 성공 경로는 30° 간격 핵심 프레임 12장 사용
- 특징점 0.35MP, seam 0.1MP, 합성 0.6MP 제한
- 전체 36장 자동 재시도 제거
- Tilt 행 정렬의 원형 이동을 공통 영역 crop 정렬로 교체
- 건물/사다리가 중간에서 잘리는 wrap seam 제거

13. 메인 창 Windows형 조작
- 34px WindowChrome caption 및 8px 가장자리/모서리 resize
- 입력 컨트롤을 제외한 화면 배경 좌클릭 drag로 창 이동
- drag 임계값 적용으로 일반 클릭 및 더블클릭 보존
- 최대화/복원 상태에 맞춘 단일/겹친 사각형 아이콘과 ToolTip
- 최대화 시 사각 모서리, 복원 시 둥근 모서리 적용
